# Changelog

All notable changes to Jwala are recorded here, newest first.

## [Unreleased]

## [0.3.3] - 2026-11-19

### Added
- **Window position (Rust and C#):** the standalone reopens where it was last closed. If any part of it would be off screen (a monitor unplugged, a lower resolution), it's pulled fully inside the nearest screen's usable area, clear of the taskbar, menu bar, Dock or panels. Windows, macOS and Linux (X11).

### Changed
- **Fonts (Rust and C#):** the UI's fonts are now built into the app, so text looks the same on Windows, macOS and Linux instead of depending on what each system has installed. Segoe UI is replaced by Selawik (its open, same-width substitute), Arial Bold by Arimo Bold, and the symbol font by DejaVu Sans. Pedal names and other text sized to the line height match the old Segoe UI layout.
- **Logo (Rust and C#):** the "Jwala" title in the header and on the splash is now an image rendered from Segoe Script Bold, so it keeps its original look everywhere.

### Version
- Bumped to 0.3.3 in `rust/Cargo.toml` and `legacy-csharp/src/Jwala.csproj`.

## [0.3.2] - 2026-11-18

### Added
- **Startup splash screen:** the standalone shows the fire splash while it loads, then reveals the main window only once it has drawn, so there's no blank or half-painted window at launch. Native on Windows (Rust and C#), macOS (an `NSWindow`) and Linux (an X11 window).

### Changed
- **Tuner page:** new LED dot-matrix display behind a glass screen, on a plain black background. The layout is unchanged (Rust and C#).
- **Knobs:** new chrome knob graphics for the amp and the cab.
- **EQ faders:** chrome fader caps with soft drop shadows, replacing the flat drawn thumbs (Rust and C#).

### Fixed
- **Text on macOS and Linux:** the UI now loads the closest system equivalents of the Windows fonts (picking faces inside macOS `.ttc` collections), so labels no longer go missing off Windows.
- **Updater:** installed VST3/CLAP plugins are now updated on the background download thread instead of during install. Waiting on the admin (UAC) prompt from the UI thread could abort the app.
- **EQ page (C#):** turning EQ ON/OFF now repaints every fader cap and slot glow, not just the switch.

### Version
- Bumped to 0.3.2 in `rust/Cargo.toml` and `legacy-csharp/src/Jwala.csproj`.


## [0.3.1] - 2026-11-16

### Added
- **In-app updater (standalone, Rust):** the standalone checks the GitHub releases page for a newer version. If it finds one, a banner under the header offers **INSTALL**, **SKIP** or **LATER**. ⚙ Settings has a new **UPDATES** row with an **AUTO-UPDATE** on/off toggle and a **CHECK NOW** button. The update zip for your platform is verified against the release's `.sha256` file before anything is replaced. The app then saves its state, swaps itself for the new build and restarts. The old copy is cleaned up on the next launch.
- **Plugin updates:** the in-app updater also updates any VST3/CLAP plugins you already have installed. Plugins in folders that need admin rights are updated through a one-time elevated prompt. A host that has the plugin loaded keeps using the old one until it restarts. After the restart, a note shows the new version and which plugins were updated.
- **App icon on macOS and Linux:** the standalone sets the fire icon at runtime (the Dock on macOS, the window icon on Linux/X11). `rust/build.sh` now packages `Jwala.app` (with `Info.plist` and `.icns`) on macOS, and the binary with `jwala.desktop`, icons and `install-linux.sh` on Linux. The icon set lives in `assets/appicon/`, generated by `tools/make_app_icons.py`.

### Changed
- **Amp cab graphic:** new grille cloth and minor touch-ups to the cab artwork.

### Version
- Bumped to 0.3.1 in `rust/Cargo.toml` and `legacy-csharp/src/Jwala.csproj`.


## [0.3.0] - 2026-11-15

### Added
- **LEAD II channel, phase 4:** two new factory presets, *Lead II Rhythm* and *Lead II Solo*.
- New factory presets: *Aggro Lush* (LEAD II with shimmer reverb and EQ) and *Acoustic Lake* (acoustic channel with shimmer reverb and EQ).
- **TAPE ECHO:** new **DIFFUSE** knob, which blooms the repeats into a wash. Wide pedals can now have up to 8 knobs, laid out 4 per row.
- **SAVE dialog:** the preset name field now has a movable caret. Left/Right, Home/End and Delete work, and you can type or backspace anywhere in the name (Rust).
- Before/after comparison renders in `samples/reverb_compare/` and `samples/cab_compare/`.

### Changed: UI and presets
- **UI is now grayscale:** the knob, header, dialogs, cab, EQ and tuner pages use a neutral gray theme instead of the gold accents (Rust and C#).
- **Factory presets reworked** (Rust and C#). *Modern Metal* and *Soaring Solo* are gone; the 14 factory presets are now Init, Glass Clean, Ambient Shimmer, Classic Crunch, Blues Lead, Lead II Rhythm, Lead II Solo, Aggro Lush, Fuzz Wall, Rodent Grunge, Acoustic 1–3 and Acoustic Lake. *Init* now sets a clean neutral starting point, *Ambient Shimmer* is retuned on the clean channel, and *Glass Clean* adds shimmer.
- **New app icon** (fire icon, `assets/app.ico`, sources in `icons/`). The C# version now uses the same shared icon file, and the old `legacy-csharp/src/app.ico` is deleted.

### Changed: high-quality DSP pass (Rust)
- **CATHEDRAL reverb / shimmer:** rebuilt as a lush stereo hall. It has per-channel pre-delay and input diffusion, and a 16-line Hadamard FDN with allpass diffusers, high damping and a separate low-band decay per line. Line lengths wander slowly. Shimmer is now a phase-aligned octave-up grain shifter fed back into the tank, so it holds a steady octave without warble, and the send scales with decay.
- **TAPE ECHO:** glide, wow, flutter and random speed drift. Repeats run through a tape head model, so they darken and saturate from the first repeat on.
- **RODENT distortion:** now two-stage soft clipping.
- **DOUBLER:** two synthetic takes (one a few cents sharp, one flat) that get retimed note by note, each with its own wandering level and tone. Each take is phase-scrambled so the mono sum doesn't comb, and the image stays centred.
- **SQUEEZE compressor:** smooth sustainer that reads levels from a held peak of a low-cut sidechain, with timing done in dB, so held low notes no longer distort. Release depends on the material (fast after a pick transient, slow after held passages). It has a 12 dB soft knee and keeps a little more of the top end.
- **GREEN DRIVE overdrive:** circuit-modelled mid-hump with a diode feedback clipper and an active tone control.
- **MUFFLER fuzz:** circuit-modelled, with two diode-feedback clipping stages and a scooped passive tone stack.
- **TRI CHORUS:** three voices per side on LFOs spaced 120° apart (one slow, one fast), with per-voice drift, rate-compensated detune and a band-limited wet path.
- **PHASE 6 phaser:** six slightly staggered allpass stages with an exponential sweep that glides per sample. L/R run in quadrature with a slow wander, the resonance loop is band-limited and soft-saturating, and the level stays matched at any mix.
- **Graphic EQ:** nine analog-matched bells (63 Hz–16 kHz). Band gains are solved from the sliders (Välimäki & Liski cascade EQ fit), so the curve follows the sliders to within a fraction of a dB. Slider moves are smoothed and on/off crossfades. The UI curve uses the same response.
- **Cab sim:** zero-latency partitioned convolver (direct head + FFT partitions, one shared input FFT). Built-in cabs are redesigned in the frequency domain with mic-position-dependent cone breakup and a minimum-phase response, plus cabinet reflections and a diffuse tail. Each cab is two speakers × four mic positions blended with a ribbon mic, and the mic position crossfades smoothly.

### Changed: C# version
- Renamed `old-csharp-legacy/` to `legacy-csharp/`.
- Synced the C# version with the Rust version: LEAD II channel, power amp, the high-quality pedals (split into `PedalsPre.cs` / `PedalsPost.cs`), EQ and cab convolver. Renders from the two versions match to float rounding.

### Fixed
- Blurry graphics in the Rust UI. Downscaled assets now use a Lanczos mip chain, sampled as a 2×2 supersample from the next-finer mip, which matches the C# version's GDI+ HighQualityBicubic look without aliasing.
- The taskbar showed the generic icon for the standalone app. The icon is now set before GPU setup and the taskbar button is refreshed, so the taskbar picks it up (Rust).

### Version
- Bumped to 0.3.0 in `rust/Cargo.toml` and `legacy-csharp/src/Jwala.csproj`.
